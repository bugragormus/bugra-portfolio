# Buğra Görmüş | Personal Portfolio

Welcome! This is the repository for my personal portfolio website.

I am a **Data Scientist** currently pursuing my Master of Science in Artificial Intelligence at the **Università della Svizzera italiana (USI)** in Lugano, Switzerland, as a YLSY Scholar. My research and engineering work focuses on designing advanced machine learning architectures, statistical model forecasting, and robust data workflows to solve complex industrial challenges.

You can visit my portfolio to explore my research papers, featured project implementations, and professional journey.

---

## 🎨 Featured Projects

- **Padok (Gazi Derby Analytics Platform)**: A predictive analysis system correlating historic Turkish horse racing indicators, jockey standings, and owner metrics. Built on automated TJK data ingestion, SQLite normalization, and explainable feature weight backtesting.
- **Lunasol Events Platform**: A premium localized event booking system based in Luxembourg, integrating Next.js, Supabase PostgreSQL, and Cloudinary APIs.
- **Retinal Imaging ML**: A machine learning pipeline analyzing retinal scan images to detect eye diseases using custom neural classification networks.
- **Finance Report Engine**: A Streamlit business intelligence application for ingest, cleanup, and visualization of ledger data.

## ⚙️ Development & Build

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the assigned port) to view local changes.

### Production Compiles
```bash
npm run build
```
Generates a highly optimized production build.
